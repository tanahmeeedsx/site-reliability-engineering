## Core SRE Concepts

- **SLI (Service Level Indicator):** A measurable signal of service reliability.
- **SLO (Service Level Objective):** A reliability target for an SLI.
- **SLA (Service Level Agreement):** A commitment made to service users, often with consequences for missing the target.
- **Error Budget:** The amount of unreliability permitted by an SLO over a given period.
- **Toil:** Repetitive operational work that can and should be automated.
